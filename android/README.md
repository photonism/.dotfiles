# ./packages

1. download (shizuku)[https://apt.izzysoft.de/fdroid/index/apk/moe.shizuku.privileged.api] apk from computer, drag it to scrcpy
2. drag `./apps/shizuku.json` to scrcpy
3. start shizuku via wireless debug (needs `adb tcpip 5555` if android < 11) or root

## obtainium

1. download (obtainium)[https://f-droid.org/packages/dev.imranr.obtainium.fdroid/] apk from computer, drag it to scrcpy
2. drag `./apps/obtainium.json` to scrcpy, open obtainium, `Add - Obtainium import`
3. go to `Settings`, set installation method `Shizuku`, configure github token
4. refresh, selected apps, `Actions - Install/update selected apps`

## droid-ify

1. download (droid-ify)[https://f-droid.org/packages/com.looker.droidify/] apk from computer, drag it to scrcpy
2. drag `./apps/droid-ify.json` to scrcpy, open droid-ify, `Settings - Import favourites and settings`
3. set installer `Shizuku/Sui installer` or `Root installer`
4. refresh, open favourites, install apps
